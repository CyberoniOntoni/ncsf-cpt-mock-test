## What shipped (deepened)

| Area | Depth |
|------|--------|
| **Constraints** | Injury flags → prefer/avoid; builder scores & hard-skips; summary in meta |
| **Substitutions** | Pattern + muscles + equipment + **constraint profile** + difficulty bias; safer swaps for injuries |
| **Mesocycle** | W1–6; **baseline prescriptions** so re-apply does not compound; strip notes; next week; calendar week from `createdAt` |
| **Correctives** | Assessment + injury → warmups; insert on existing program |
| **Regenerate** | **In-place rebuild** (`regenerateProgramInPlaceAction`) keeps program id/status/client |

### Server actions

- `suggestSubstitutionsAction` — constraint-aware ranking when client assigned  
- `applyMesocycleToProgramAction` — scales from `generationMeta.baselinePrescriptions`  
- `advanceMesocycleWeekAction` — W → W+1 (wrap 6→1)  
- `regenerateProgramInPlaceAction` — rebuild days/exercises  
- `suggestProgramMesocycleWeekAction` — calendar week hint  
- `insertCorrectivesAction` — assessment/injury warmups  

### UI

- **Wizard**: mesocycle week chips + deload cue + programming brain preview card  
- **Program detail**: week chips, Apply / Next week / Use calendar, Insert correctives, **Regenerate program**, constraint summary, smart swap with scores & reasons
